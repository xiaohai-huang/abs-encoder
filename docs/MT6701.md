# MT6701 Datasheet — Hall Based Angle Position Encoder Sensor

**Manufacturer:** MagnTek (www.magntek.com.cn)
**Document Revision:** 1.8 (December 2022)
**Package Options:** SOP-8, QFN3x3-16L

---

## 1. General Description

The MagnTek MT6701 is a rotary position sensor IC based on Hall sensing technology. It senses the Z-Axis component of a rotating magnet in the X-Y plane and delivers two sinusoidal output signals to an internal DSP, indicating the angle (α) between the sensor and the magnetic field direction.

Key capabilities:
- 0°–360° full-range absolute angle sensing
- 14-bit absolute angle resolution
- Incremental ABZ output (up to 1024 PPR / 4096 steps per revolution)
- UVW commutation output (1–16 pole pairs)
- I2C and SSI digital interfaces
- Analog (12-bit DAC) and PWM outputs
- Contactless pushbutton detection via PUSH pin

## 2. Features and Benefits

- Hall sensing technology, 0°–360° full-range angle sensing
- 3.3–5.0V operation supply; built-in EEPROM (programming at VDD > 4.5V)
- Independent output interfaces: I2C, SSI, ABZ, UVW, Analog/PWM, Push-Button
- Maximum rotation speed: 55,000 RPM
- Output propagation delay: < 5 µs
- ABZ resolution: 1–1024 PPR (user programmable)
- UVW resolution: 1–16 pole pairs (user programmable)
- RoHS compliant (2011/65/EU)
- SOP-8 and QFN3x3-16L packages

## 3. Applications

- Absolute linear position sensor
- Robotics control
- Contactless knob
- Contactless potentiometer
- Optical encoder replacement

## 10. Output Modes

### 10.1 ABZ Quadrature Output

- CCW rotation: B leads A by 1/4 cycle
- CW rotation: A leads B by 1/4 cycle
- Z indicates zero position (user programmable)
- After power-on, ABZ output blocked for 50ms
- Optional: power-on AB pulses indicating absolute position
- Resolution: 1–1024 PPR (user programmable via 10-bit register ABZ_RES)
- Z pulse width options: 1, 2, 4, 8, 12, 16 LSBs, or 180°

### 10.2 UVW Output

- U, V, W pulses 120° (electrical) out of phase
- Pole pairs: 1–16 (user programmable via 4-bit register UVW_RES)
- QFN-16 package provides dedicated U, V, W pins (pins 11, 12, 9)

### 10.3 Analog Output

- 12-bit DAC, rail-to-rail
- Linear transfer: angle → voltage proportional to VDD
- Start/stop angles programmable (A_START, A_STOP registers)
- Clamp_Low and Clamp_High programmable
- Enable: register OUT_MODE = 0

### 10.4 PWM Output

- Duty cycle proportional to measured angle
- 12-bit resolution
- Frame: 4119 PWM clock periods
- One clock period = 0.088° (typ. 244ns, programmable to 488ns)
- Frequency: 994.4 Hz or 497.2 Hz (programmable)
- Enable: register OUT_MODE = 1

### 10.5 I2C Interface

- Slave mode
- Default 7-bit slave address: 0b0000110 (0x06); programmable to 0b1000110
- Angle data in registers 0x03 (bits [13:6]) and 0x04 (bits [5:0])
- Read 0x03 first, then 0x04
- Angle formula: θ = (Σ Angle[i] × 2^i, i=0..13) × 360 / 16384
- Pull-up resistors: 4.7KΩ on SDA and SCL

### 10.6 SSI Interface

- CSN (active low) starts transfer
- Data driven on rising edge of CLK, captured on falling edge
- CLK idle high

#### SSI Data Format (24 bits total)

| Bits | Content |
|------|---------|
| 0–13 | 14-bit Angle Data D[13:0] |
| 14–17 | 4-bit Magnetic Field Status Mg[3:0] |
| 18–23 | 6-bit CRC Code CRC[5:0] |

- Angle formula: θ = (Σ D[i] × 2^i, i=0..13) × 360 / 16384
- CRC polynomial: X^6 + X + 1, MSB first
- CRC covers D[13:0] and Mg[3:0] (18 bits total)

## 12. EEPROM Programming Procedure

**Requirement: VDD must be between 4.5V and 5.5V during programming.**

| Step | Operation |
|------|-----------|
| 1 | Write the desired value to target EEPROM register(s). Read-modify-write: read existing bits, OR with new bits. Do NOT change reserved bits. |
| 2 | Write 0xB3 to register 0x09 (Programming Key) |
| 3 | Write 0x05 to register 0x0A (Programming Command) |
| 4 | Wait > 600ms without any I2C operation |
| 5 | Power-down MT6701, then power-up again |
| 6 | Read back EEPROM registers to verify programming |

## 15. Mechanical Angle Direction

- Viewed from top of package
- 0°: between Pin 1 and Pin 2 (SOP-8) / toward Pin 1 side (QFN-16)
- 90°: toward Pin 3/4 side
- 180°: toward Pin 5/6 side
- 270°: toward Pin 7/8 side
- Angle increases counter-clockwise (CCW) by default (DIR=0)

## 16. Reference Circuit Notes

- Decoupling capacitor: 0.1µF between VDD and GND (required)
- TVS diode (6V) on VDD recommended for better reliability
- I2C pull-up resistors: 4.7KΩ on SDA and SCL
- MODE and Z pins have internal 200KΩ pull-up resistors

## 17. Internal Architecture

- CMOS process
- Magnetic sensing element array (two interleaved Wheatstone bridges → sine/cosine)
- Gain stages
- ADCs for signal conditioning
- DSP unit for angle calculation and interpolation
- 12-bit DAC for analog output
- LDO
- EEPROM for configuration storage
- Oscillator (OSC)

## 18. Key Formulas

### Angle Calculation (I2C / SSI)
θ (degrees) = Angle_value × 360 / 16384
Where Angle_value is the 14-bit raw data (0–16383).

### Ratiometric Error
Erm = [(Vout/VDD_actual) - (Vout_5V/5V)] × 100%

### ABZ Resolution Relationship
PPR = ABZ_RES register value  
Steps per revolution = PPR × 4  
LSB = 360° / (PPR × 4)
